# VOLTEX (static version: HTML + CSS + JavaScript)

## باز کردن سایت
روی `index.html` دوبار کلیک کنید. نیازی به پایتون، نصب یا اینترنت برای خود سایت نیست (فقط فونت‌ها از اینترنت می‌آیند).

## تغییر محتوا (جای پنل مدیریت)
1. `admin.html` را روی کامپیوتر خودتان باز کنید.
2. متن معرفی، تماس، کارت‌های نرم‌افزار، خدمات، ربات‌ها و آموزش‌ها را ویرایش کنید (افزودن، حذف، جابه‌جایی).
3. دکمه Download content.js را بزنید و فایل دانلودشده را جای `js/content.js` بگذارید.
4. این فایل admin.html را روی سایت عمومی آپلود نکنید.

## فرم عضویت
سایت ثابت جایی برای ذخیره ندارد. در formspree.io یک فرم بسازید، آدرس آن (مثل https://formspree.io/f/xxxx) را در admin.html در فیلد Membership form URL بگذارید. لیست عضوها فقط در ایمیل یا داشبورد خودتان می‌ماند و در سایت دیده نمی‌شود.

## گذاشتن روی GitHub Pages
1. در github.com یک Repository بسازید.
2. فایل‌ها (index.html، پوشه css، پوشه js) را آپلود کنید؛ admin.html را نه.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و پوشه / (root) ← Save.
4. بعد از چند دقیقه آدرس سایت در همان صفحه نمایش داده می‌شود.

## نکته
نام نرم‌افزارها، خدمات، ربات‌ها، متن معرفی و پاسخ سوالات متداول نمونه هستند. حتماً در admin.html با اطلاعات واقعی خودتان جایگزین کنید.
